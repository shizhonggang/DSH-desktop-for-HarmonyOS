# 图标改版前的原始素材（2026-10-10）

归档原因：按用户要求把 app logo 从「黑鲸鱼 + 白底」改为「**白鲸鱼 + 黑底**」，
并把鲸鱼主体从占画布 **60% 宽**放大到 **70% 宽**（中途试过 82%，用户反馈太大，最终定 70%）。

保留价值：原始素材可用于回滚、也可复用其**轮廓 alpha**（见下）。

## 文件
12 个改动前的 PNG，文件名用 `_` 替代原路径分隔符，例如：
- `AppScope_resources_base_media_foreground.png` = 原前景层（**黑色鲸鱼**，透明底）
- `entry_src_main_resources_base_media_startIcon.png` = 原启动图标（黑鲸鱼 + 白底）
- `app_icon_1024x1024.png` / `app_icon_216x216.png` = 仓库根目录的图标预览

## 关键发现（复现要点）
1. **鲸鱼轮廓在所有变体里像素完全一致**，只是填充色不同：
   - `base/media/foreground.png` = 黑鲸鱼透明底；`dark/media/foreground.png` = 白鲸鱼透明底
   - 两者 `alpha` 通道**逐像素相等**（已实测 `np.array_equal == True`）
   → 所以换色/缩放只需从**任一**变体取 alpha 当遮罩，不必描边重画。
2. 新图标就是从这个 alpha 派生的：裁到 bbox → 统一比例缩放到画布宽 70%（717px）→
   LANCZOS 后按 ≥128 重新二值化（避免缩放产生灰边）→ 居中贴回 → 分别合成
   `foreground`（白鲸鱼+透明底）/ `background`（纯黑满幅）/ `startIcon`&`app_icon`（黑底白鲸鱼的扁平图）。
3. `layered_image.json` 只存在于 `base/media/`，dark 变体靠同名资源自动覆盖，未改配置。

未删除任何内容（用户原则：冗余/退役文件不删除、归档备查）。

## 追加：视觉重心修正（2026-10-10 第二轮）
用户反馈「视觉重心有点靠左」。实测确认：
- bbox 居中是 511.5（对的），但**墨迹质心只有 491**（左偏 20.5px）——
  右侧的尾鳍/喷气几乎不占面积，左侧头身是大色块，所以按 bbox 居中被眼睛判为偏左。
- 垂直方向质心 495.2，也比 bbox 中心高 16.3px。

改法：不再按 bbox 居中，改为**按墨迹质心（ink centroid）居中**——
`ox = 512 - Σ(col·x)/Σcol`，垂直同理。结果质心落在 (512.0, 512.2)。
代价是 bbox 变成**故意不对称**：左右边距 175 / 133，上下 260 / 226。
这是光学居中的正常结果，不是 bug——**下次谁再"顺手把 bbox 居中"，就会把偏左改回来**。
